# Security Policy

## Reporting a vulnerability

Do not disclose a suspected security vulnerability in a public issue, discussion, or pull request.

Use the repository's **Security** tab and select **Report a vulnerability** to submit a private report through GitHub Private Vulnerability Reporting. Include the affected version, impact, reproduction steps, and proposed mitigation when available. Do not include unrelated personal data, real location history, bump exports, or sensor recordings.

If private reporting is unavailable, open a public issue containing no vulnerability details and request a private reporting channel.

## Supported version

Security updates target the current release on `main`. BumpCompanion stores potentially sensitive coordinates locally in browser storage. Reports involving origin isolation, import validation, service-worker scope, or unintended network disclosure are especially useful.
