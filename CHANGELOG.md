# Changelog

All notable user-facing changes to BumpCompanion Web are documented here.

## 1.0.0 - 2026-08-07

### Added

- Initial public iOS-first Progressive Web App release.
- Detector-v2 TypeScript port with timestamp-aware signal processing, adaptive baseline, structured event windows, seven bump profiles, and explicit false-positive rejection.
- User-initiated Drive Mode with iOS motion permission, geolocation, Web Audio/Speech Synthesis warnings, and Screen Wake Lock support.
- Local candidate review, saved-bump library, Leaflet/OpenStreetMap view, trajectory-aware approach warnings, drive history, and calibration.
- IndexedDB persistence with versioned schema and validated `.bumpcompanion` import/export.
- Installable manifest, Apple touch icon, safe-area layout, offline application shell, automated tests, CI, and GitHub Pages deployment.
